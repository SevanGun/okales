# ОКАЛЕС — сайт зеркала «Еиналеж»

Одностраничный сайт для продажи напольного зеркала в стиле «Гарри Поттера».
Домен: **www.okales.ru**
Чистые HTML / CSS / JS — работает на любом хостинге, без сборки и без сервера.

## Файлы

```
index.html      главная страница (весь контент)
privacy.html    политика конфиденциальности
styles.css      стили
script.js       конфигуратор, формы, галерея  ← настройки в начале файла
robots.txt
sitemap.xml
watermark.py              нанесение логотипа на фотографии
deploy.sh                 сборка папки dist/ для заливки на хостинг
assets/
  _original/                чистые фото без знака — на сервер не уходят
  logo.svg                  логотип ОКАЛЕС для тёмного фона
  logo-dark.svg             он же для светлого фона
  mark.svg                  знак без надписи

  interior/*.jpg            6 фото в интерьере (-sm — превью для сетки)
  production/*.jpg          5 фото из цеха (-sm — превью)
```

## Цены

Всё в `script.js`, объект `CONFIG.prices`:

```js
base: 100000,                // базовая модель 2100×1000, массив дуба
options: { led: 12000, engrave: 6000, custom: 15000, mount: 8000 }
```

Цена в микроразметке `Product` в `index.html` (`"price": "100000"`) правится отдельно —
её показывают Яндекс и Google в выдаче, она должна совпадать с базовой.

## Куда приходят заявки

По умолчанию `CONFIG.formEndpoint` пустой — кнопка открывает Telegram с уже
набранным текстом заявки. Это рабочий вариант на старте, ничего настраивать не нужно.

Чтобы заявки падали на почту/в CRM, заведите форму в любом сервисе
(Formspree, Getform, Форма от Тильды, свой php-скрипт) и впишите URL:

```js
formEndpoint: 'https://formspree.io/f/xxxxxxx',
```

Данные уходят POST-запросом в JSON: `name`, `phone`, `message`, `config`, `source`, `page`.
В формах уже стоит скрытая ловушка для ботов (поле `company`).

## Публикация на хостинге

### 1. Собрать папку для заливки

```bash
cd potter-mirrors && ./deploy.sh
```

Скрипт создаёт `dist/` — 43 файла, 6,3 МБ. Туда попадает только то, что должно быть
публичным: `README.md`, `preview.html` и `build-preview.py` остаются на компьютере.

### 2. Залить содержимое dist в корень сайта

Корень на разных хостингах называется по-разному: `public_html`, `www`, `htdocs`
или `okales.ru/public_html`. Заливать нужно **содержимое** `dist`, а не саму папку —
`index.html` должен лежать прямо в корне.

**Через панель хостинга.** Файловый менеджер → корень сайта → загрузить.
Удобнее заранее упаковать: `cd dist && zip -r ../site.zip . -x '.DS_Store'` — панели
умеют распаковывать архив на сервере.

**Через FTP.** FileZilla или Cyberduck, данные для входа — в панели хостинга.

**Через SSH, если он есть** — самый быстрый способ обновлять сайт потом:

```bash
rsync -avz --delete dist/ ПОЛЬЗОВАТЕЛЬ@okales.ru:~/public_html/
```

> **Важно:** `.htaccess` — скрытый файл, Finder и часть FTP-клиентов его не показывают.
> В Finder скрытые файлы включаются сочетанием **Cmd + Shift + точка**, в FileZilla —
> «Сервер → Принудительно отображать скрытые файлы». Без `.htaccess` не будет ни
> склейки зеркал, ни редиректа на https, ни страницы 404.

### 3. Домен и сертификат

- В DNS: A-запись `okales.ru` на IP хостинга и CNAME `www` на `okales.ru`
  (либо обе A-записи — как требует хостинг).
- В панели включить бесплатный SSL (Let's Encrypt). **Без HTTPS сайт нельзя
  запускать**: на нём форма с персональными данными, это требование 152-ФЗ,
  плюс браузеры помечают такие сайты как небезопасные.
- Канонический адрес сайта — `https://www.okales.ru/`, он прописан в `<link rel="canonical">`,
  `sitemap.xml` и `.htaccess`. Если решите жить без `www`, поменяйте его во всех трёх местах.

### 4. Проверить после заливки

```
https://www.okales.ru/           открывается
http://okales.ru/                редиректит на https://www.okales.ru/
https://www.okales.ru/robots.txt отдаётся
https://www.okales.ru/sitemap.xml отдаётся
https://www.okales.ru/несуществующая-страница  показывает свою 404
```

Отдельно: отправить тестовую заявку из формы и убедиться, что она дошла. Сейчас при
пустом `formEndpoint` кнопка открывает Telegram — **проверьте, что канал `@okales`
действительно существует**, иначе заявки будут уходить в никуда.

### Если хостинга пока нет

Для статического сайта хватит бесплатного: Netlify (папку `dist` можно просто
перетащить в браузер), Cloudflare Pages или GitHub Pages. Домен `okales.ru`
прикручивается в настройках. Учтите: `.htaccess` там не работает — редиректы
настраиваются средствами самой платформы (`_redirects` у Netlify).

## Аналитика

Перед `</body>` в `index.html` вставьте счётчики Яндекс.Метрики и Google Analytics.
Цели удобно вешать на события форм — обе формы отправляются через `bindForm()` в `script.js`,
там же после успешной отправки можно добавить `ym(ID,'reachGoal','lead')`.

## Юридическое

В подвале и на странице политики стоит дисклеймер о том, что сайт не аффилирован
с Warner Bros. и правообладателями франшизы. Не удаляйте его: при использовании
названия «Гарри Поттер» в коммерческих текстах это снижает риск претензий и
отклонения объявлений на модерации в Яндекс.Директ и VK Рекламе.

## Фирменный стиль

Логотип взят из `Desktop/other/Web_make_ok/stool-okales` и пересобран в чистый SVG:
белые контуры вынесены в отдельные файлы под тёмный и светлый фон, оранжевая точка
сохранена как есть.

Фирменный оранжевый `#EC6E18` заведён в CSS как токен `--brand` и используется точечно —
в маркерах списка и номерах шагов. Основной акцент интерфейса остался латунно-золотым
(`--gold`, `#B0842C`): он ближе к дубу и патине на фотографиях изделия. Если нужно
сделать сайт полностью оранжевым, достаточно поменять `--gold` и `--gold-l` в начале
`styles.css` — все кнопки, ссылки и рамки подхватят цвет автоматически.

## SEO: что уже настроено

**На странице**
- `<title>` 58 знаков и `description` 155 знаков — обе влезают в сниппет без обрезки
- Один `H1` с главным запросом, дальше `H2` по разделам без пропусков уровней
- `canonical` на `https://www.okales.ru/`, директива `robots` с `max-image-preview:large`
  (крупная картинка в выдаче Google)
- Open Graph и Twitter Card целиком, включая размеры и `alt` картинки — ссылка в
  Telegram, VK и WhatsApp разворачивается в карточку
- Осмысленный `alt` у каждой фотографии, у всех проставлены `width`/`height`
- SEO-текст внизу переписан под живые запросы, со ссылками на разделы страницы

**Микроразметка** (один блок `@graph` в `<head>`)
- `Organization` — ОКАЛЕС, логотип, телефон, адрес, Telegram
- `WebSite`
- `Product` — материал, габариты, вес, гарантия, срок изготовления, цена и `Offer`
- `FAQPage` — все 6 вопросов; собраны скриптом прямо из вёрстки, поэтому текст
  разметки совпадает с видимым (Google это проверяет). **Если правите вопросы в FAQ —
  поправьте и разметку**, иначе блок отвалится из выдачи.

Проверить после публикации: `search.google.com/test/rich-results` и
`webmaster.yandex.ru/tools/microtest`.

**Файлы**
- `robots.txt` — с `Clean-param` для utm-меток, чтобы реклама не плодила дубли
- `sitemap.xml` — страница плюс 12 изображений с подписями (попадание в поиск по картинкам)
- `.htaccess` — склейка зеркал (http→https, без www → с www, `/index.html` → `/`),
  сжатие, кэш браузера, заголовки безопасности, 404
- `404.html` — своя страница ошибки

**Скорость** (Core Web Vitals — фактор ранжирования)
- `preload` главного фото, оно же LCP-элемент
- `preconnect` к Google Fonts, шрифты с `display=swap`
- `defer` у скрипта, `loading="lazy"` у всех фото ниже первого экрана
- Размеры у всех картинок — нулевой сдвиг вёрстки (CLS)
- Все фото пережаты: 20 МБ исходников → 4,4 МБ, для сеток отдельные превью

## SEO: что нужно сделать вам

1. **Заменить заглушки** — реквизиты ИП и адрес (телефон уже настоящий). Они попадают в микроразметку
   `Organization`, а НКО-данные с чужим ИНН лучше не индексировать.
2. **Яндекс.Вебмастер** — добавить сайт, подтвердить права (код в `<head>`, строки
   закомментированы), загрузить sitemap, заполнить регион показа.
3. **Google Search Console** — то же самое.
4. **Яндекс.Метрика** — раскомментировать заготовку перед `</body>`, подставить номер
   счётчика, включить вебвизор, повесить цель на отправку формы.
5. **Яндекс.Бизнес** — карточка организации, она же тянет отзывы и адрес в карты.
6. **Отзывы.** Раздела с отзывами на сайте нет намеренно: размечать `aggregateRating`
   без реальных отзывов — прямое нарушение правил Google и повод снять сниппет.
   Появятся настоящие — добавим блок и разметку.

## Водяной знак

Логотип нанесён на все 16 фотографий — интерьеры, цех и картинку для соцсетей.
Ширина знака — треть ширины кадра, отступ от верхнего левого угла 3,5 %.

```bash
.venv/bin/python watermark.py
```

Скрипт при первом запуске откладывает чистые оригиналы в `assets/_original/` и дальше
читает только их, поэтому его можно запускать сколько угодно раз — знак не наложится
дважды. Превью для сеток (`-sm`) пересобираются из уже подписанного кадра, так что
доля в треть ширины сохраняется на любом размере.

Знак сплошной белый, полупрозрачный, без ореола и тени — одинаковый на всех кадрах.
Для этого рядом с обычным логотипом лежит `assets/logo-white.svg`, где залита белым
и фирменная точка тоже: в полупрозрачном знаке одиночное оранжевое пятно смотрится
случайным. Вернуть точку — поставить `LOGO_FILE = 'logo'`.

Настройки — в начале `watermark.py`:

| Константа | Сейчас | Что делает |
|---|---|---|
| `WIDTH_RATIO` | `1/3` | ширина знака от ширины кадра |
| `MARGIN_RATIO` | `0.035` | отступ от угла |
| `OPACITY` | `0.35` | плотность знака: 1.0 — сплошной, 0.25 — еле заметный |
| `LOGO_FILE` | `logo-white` | `logo` — вернуть оранжевую точку |
| `HALO` | `False` | ореол и тень под знаком |
| `AUTO_COLOR` | `False` | тёмный знак на светлых фото, светлый на тёмных |
| `LIGHT_THRESHOLD` | `145` | граница яркости для `AUTO_COLOR` |

Поменяли значение — запустите скрипт заново, затем `./deploy.sh`.
Оригиналы в `assets/_original/` не удаляйте: без них вернуть чистые фото уже нельзя.
